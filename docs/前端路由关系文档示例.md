# 前端项目路由关系文档示例

> 适用于记录 **SPA 前端项目（如 Angular / React / Vue）** 的路由设计，用于开发协作、维护与交接。

---

## 1. 文档说明

- **项目名称**：Example CMS Frontend
- **框架**：Angular 16
- **路由模式**：History API（PathLocationStrategy）
- **是否启用懒加载**：是
- **权限控制**：基于角色（Role-based Access Control）

---

## 2. 路由总体结构

```text
/
├── login
├── dashboard
├── articles
│   ├── list
│   ├── create
│   └── :id/edit
├── users
│   ├── list
│   └── :id
└── settings
```

---

## 3. 路由表（Route Table）

| 路径 Path | 组件 Component | 模块 Module | 是否懒加载 | 权限要求 | 说明 |
|---------|---------------|-------------|------------|----------|------|
| `/login` | LoginComponent | AuthModule | 否 | 无 | 登录页 |
| `/dashboard` | DashboardComponent | DashboardModule | 是 | USER / ADMIN | 控制台首页 |
| `/articles` | ArticleLayoutComponent | ArticleModule | 是 | EDITOR / ADMIN | 文章模块布局 |
| `/articles/list` | ArticleListComponent | ArticleModule | 是 | EDITOR / ADMIN | 文章列表 |
| `/articles/create` | ArticleCreateComponent | ArticleModule | 是 | EDITOR | 新建文章 |
| `/articles/:id/edit` | ArticleEditComponent | ArticleModule | 是 | EDITOR | 编辑文章 |
| `/users` | UserListComponent | UserModule | 是 | ADMIN | 用户列表 |
| `/users/:id` | UserDetailComponent | UserModule | 是 | ADMIN | 用户详情 |
| `/settings` | SettingsComponent | SettingsModule | 是 | ADMIN | 系统设置 |

## 4. 路由配置示例（代码）

### 4.1 根路由（app-routing.module.ts）

```ts
const routes: Routes = [
  { path: '', redirectTo: 'dashboard', pathMatch: 'full' },
  { path: 'login', component: LoginComponent },
  {
    path: 'dashboard',
    loadChildren: () => import('./modules/dashboard/dashboard.module')
      .then(m => m.DashboardModule),
    canActivate: [AuthGuard]
  },
  {
    path: 'articles',
    loadChildren: () => import('./modules/article/article.module')
      .then(m => m.ArticleModule),
    canActivate: [AuthGuard]
  },
  { path: '**', component: NotFoundComponent }
];
```

---

## 5. 路由守卫说明（Guards）

| Guard 名称 | 类型 | 作用 |
|-----------|------|------|
| AuthGuard | canActivate | 校验是否登录 |
| RoleGuard | canActivate | 校验用户角色 |
| UnsavedGuard | canDeactivate | 防止表单未保存离开 |

示例：

```ts
{
  path: 'articles/create',
  component: ArticleCreateComponent,
  canActivate: [RoleGuard],
  data: { roles: ['EDITOR'] }
}
```

## 6. 动态路由与参数说明

| 路由 | 参数 | 说明 |
|------|------|------|
| `/articles/:id/edit` | id | 文章 ID |
| `/users/:id` | id | 用户 ID |

组件中获取方式：

```ts
this.route.snapshot.paramMap.get('id');
```

---

## 7. 路由与菜单映射关系

| 菜单名称 | 路由 | 是否显示 | 备注 |
|---------|------|----------|------|
| 控制台 | `/dashboard` | 是 | 所有登录用户 |
| 文章管理 | `/articles/list` | 是 | 编辑及管理员 |
| 新建文章 | `/articles/create` | 否 | 通过按钮进入 |
| 用户管理 | `/users` | 是 | 管理员 |
| 系统设置 | `/settings` | 是 | 管理员 |

---

## 8. 特殊说明

- 所有业务模块均采用 **Lazy Loading**，减小首屏体积
- 路由权限与后端接口权限保持一致
- URL 命名统一使用 **kebab-case**
